# Justin's Ethical Hacking / CEH Portfolio

Public, evidence-based record of my self-directed journey into cybersecurity — from networking fundamentals through to OSCP-level offensive security skills. This repo is proof-of-work: every entry reflects something I actually studied, practiced, and verified hands-on, not just theory I read about.

## About This Repo

I'm working through a self-structured 15-phase ethical hacking curriculum alongside university entrance exam prep. This portfolio tracks the cybersecurity side of that work. Notes start as working drafts in Obsidian, and once a topic is complete — concept understood, hands-on practice done, results logged — the polished version gets committed here.

Each entry generally follows the same lifecycle:

1. Study the concept
2. Do the hands-on practice
3. Log the result
4. Write it up
5. Commit it here, and tick it off in my tracking system
